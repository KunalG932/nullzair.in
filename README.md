# nullzair.in

Personal portfolio of Kunal Gaikwad, Full Stack Developer and MCA candidate. Built with vanilla HTML, CSS, and JavaScript.

- Live Site: https://nullzair.in
- GitHub: https://github.com/KunalG932
- LinkedIn: https://linkedin.com/in/coolnano

## Tech Stack

- Frontend: Semantic HTML5, Vanilla CSS3, Modern JavaScript (ES6+)
- Smooth Scroll: Lenis
- Fonts: Outfit, Inter, Noto Sans Devanagari
- Deployment: Vercel

## Project Structure

```
nullzair.in/
|-- index.html               # Main single-page portfolio
|-- style.css                # Design system, layout, and animations
|-- script.js                # Interactions and scroll handling
|-- vercel.json              # Vercel deployment configuration
|-- KunalGaikwadResume.pdf   # Downloadable ATS-friendly resume
|-- hero-image.png           # Profile photo asset
|-- noise.png                # Grain overlay texture
`-- README.md                # Project documentation
```

## Running Locally

Serve the project directory with any local static HTTP server:

```bash
# Python
python -m http.server 5500

# or Node
npx serve .
```

Open http://localhost:5500 in your browser.
